// Project 03

Mathematical Operations Using Loops

Enter N once. The factorial, sum, and average are each computed with a different loop.

Choose N

A whole number from 0 to 1,000. The first N natural numbers are 1, 2, 3, …, N.

Factorial

While Loop

—

N! = 1 × 2 × … × N

let result = 1, i = 1;
while (i <= n) {
  result *= i;
  i++;
}

Sum

Do While Loop

—

1 + 2 + … + N

let sum = 0, i = 1;
do {
  sum += i;
  i++;
} while (i <= n);

Average

For Loop

—

sum ÷ N

let total = 0;
for (let i = 1; i <= n; i++) {
  total += i;
}
let average = total / n;

Factorial uses big-integer math (BigInt), so even large results are exact. 0! = 1 by definition; the sum and average of zero numbers are shown as 0.
